#  WPF Media Player

Простой аудиоплеер с плейлистом, shuffle и удобным управлением. Учебный проект для изучения C# и WPF.

##  Возможности

- Добавление файлов в плейлист (поддерживаются .mp3, .wav, .wma, .m4a)
- Play / Pause / Stop
- Перемотка (ползунок, перетаскивание)
- Громкость (слайдер + отображение в процентах)
- Переключение треков (Next / Previous)
- Режим shuffle (случайный порядок без повторений в пределах цикла)
- Зацикливание плейлиста (автоматический переход к первому треку после последнего, если shuffle выключен)
- Очистка плейлиста и удаление выбранного трека

##  Технологии

- .NET 8 (WPF)
- MediaElement
- DispatcherTimer
- OpenFileDialog
